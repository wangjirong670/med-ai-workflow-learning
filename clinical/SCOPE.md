## 这条轨是/不是什么

| 是 | 不是 |
|----|------|
| 接诊/查房前：线索结构、时间线、矛盾点 | 代替上级下最终判断 |
| 向导师/上级汇报的一页纸 | 给患者的用药/处置方案 |
| 病例讨论：鉴别推理结构、对立解释 | 承诺诊断病名 |
| 「该问上级的问题」清单 | 急诊决策支持/医嘱 |
| 资料核对清单（化验、影像、用药史） | 以 AI 结论直接写进病历定论 |

## 临床向红线（将写入 clinical/quickstart.md）

1. **不输出最终诊断承诺、不输出可直接执行的医嘱/用药方案**。  
2. **允许**输出：鉴别假设列表、支持/反对证据（E1–E4）、需完成的评估与提问。  
3. 明确读者是**医师同行讨论**，不是患者；患者可读版本属于方向 B，不走本轨。  
4. 每次收尾固定句：「供医师讨论与资料准备，不构成诊疗建议；实施以前接诊/主管医师判断为准。」  
5. 越界（如被要求开药、下确定诊断）→ 触发【勘误】·`边界越界` 并停在讨论材料层。  
6. 紧急情况话术：提示立即线下/急诊处理，不展开远程处置。

## E 级（本轨另立，开写主流程前先答）

学习向 E1–E4 **不得**直接沿用。临床里至少四层纠缠：教材、当前指南、本院方案、**本患者数据**。  
开写 `clinical/quickstart.md` 前必须先定：个体患者数据放哪一档，或独立成类；「原始题面」不得自然映射成「患者原始资料」。

## 与学习向的分叉点

| 项 | 学习向 | 临床向 |
|----|--------|--------|
| 对照臂 | 概念误区、考法错解 | **对立鉴别**、坏方向 |
| 拍板人 | 学习者本人 | 学习者 + **上级/导师** |
| 一页纸 | 学习钉子单 | 交班条 / 病例讨论页 |
| 问谁 | 老师 | 上级医师、会诊 |
| 证据优先 | 教材章节 | 指南 + 原始病历数据 |
