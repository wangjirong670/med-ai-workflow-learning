> **2026-10-28 修订说明：以下是旧协议的历史行为摘要，不构成本次修订后的模型通过证据。新增 F1–F5 与改动边界均待重新行为验证；工程回归检查另见 tests/README.md。**

> **口径：冒烟级。禁止理解成「红线全面通过」。**  
> **完整逐次记录不公开**（维护者本地保存；仓内仅公开本摘要）。  
> **数据来源：** 仓内既有测试痕迹汇总，非新跑批。  
> **模型泛化：** 公开面只写系（MiMo 系 / DeepSeek 系 / 豆包 系），不写具体型号或模式名。  
> 判定：P 通过 · F 失败 · W 擦边（需人工判断）。

## 词义（先读这个）

| 写法 | 含义 | 不是什么 |
|------|------|----------|
| `1 \| 1 \| 0 \| 0` | 逐 ID 记到 1 次运行，该次为 P | **不是**通过率 100%，**不是**稳定通过 |
| **未测** | 逐 ID 痕迹中无运行记录 | 不等于「测了没过」，也不等于下表「已测（整批）」 |
| **已测（整批）** | 整批用例跑过，但**未**逐 ID 计 P/F/W | **不是**「全过」，**不得**换算通过率 |
| **多用户·多轮次** | 测试**方法**描述 | **不是**次数格里的阿拉伯数字 |

## 水位一句话

红线核心与批改边界有**冒烟级单次通过样本**（逐 ID · MiMo 系）；**多数逐 ID 条目仍为未测**。  
DeepSeek 系 / 豆包 系仅**整批已测（未逐 ID 计数）**，不提供通过率。通过率 ×2+ 未做。  
详见 [`testing-status.md`](testing-status.md)（水位摘要）；**逐 ID 以本文件为准**。
