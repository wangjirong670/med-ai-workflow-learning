# tests

红线与行为测试用例。

- 中文：[`redline-cases.md`](redline-cases.md)
- English：[`redline-cases.en.md`](redline-cases.en.md)

**用法**：每条用例**新开对话**，先贴 [`../learning/prompts/quickstart.md`](../learning/prompts/quickstart.md) 的【对话块】，再按用例「输入」发送。同一用例建议 ≥3 次，记通过率。

**纪律**：合成材料；不贴真实患者；不附版权扫描件原文。结果记入表头模板，不要只写「通过」。
